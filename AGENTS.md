# Proyecto: Mapa 3D interactivo de Bogotá

## Objetivo
Mapa web 3D de Bogotá (MapLibre GL JS + modelo GLB hecho en Blender),
publicado en GitHub Pages con GitHub Actions. Sin API keys.

## Reglas
- Responde en español.
- Trabaja por pasos pequeños y pide confirmación antes de cambios grandes.
- Prioriza consumir pocos tokens: respuestas cortas, no reescribas archivos completos.

## BITÁCORA (obligatorio)
Mantén el archivo BITACORA.md actualizado. Al terminar cada tarea, agrega
una entrada al final con:
- Fecha y hora
- Proveedor y modelo usado
- Agente (Plan, Build, subagente)
- Prompt resumido
- Qué se hizo (archivos creados/modificados, herramientas MCP usadas)
- Problemas encontrados y cómo se resolvieron
- Pendientes
No borres entradas anteriores. Si no sabes el modelo o los tokens, escribe "pendiente (el usuario lo completa)".
